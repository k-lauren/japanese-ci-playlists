About

日本語の独学について

This library is a project for an independent study in Language Autopedagogy — the practice of teaching oneself a language by deliberately curating the input one consumes. The target language is Japanese, and the medium is Comprehensible Input (CI): content delivered just slightly above the learner's current level, in a way that is understandable from context, gesture, and prior knowledge — without translation.

The CI hypothesis (Krashen, 1985) holds that language is acquired, not learned, by exposure to messages we can almost understand. The job of a self-directed learner, then, is to find enough such messages to surround themselves with the language. YouTube is unusually well-suited to this — a generation of teachers have built channels specifically for CI delivery — but the catalog is sprawling, the level signals are inconsistent, and the most useful content isn't always what the algorithm surfaces.

This site is one attempt at a fix: a hand-bucketed, view-ranked, tag-filterable index of the most-watched videos from established Japanese CI channels.

Selection methodology

Selection was a four-stage process. Source code and raw data are on GitHub.

1. Channel-anchored seed list. Rather than running a broad keyword search (which produces noise — generic "learn Japanese" content that isn't true CI), I started with a curated list of established Japanese CI channels: Comprehensible Japanese, Speak Japanese Naturally, Onomappu, Nihongo con Teppei, Japanese with Shun, Japanese Immersion with Asami, Sayuri Saying, Miku Real Japanese, YUYU's Japanese Podcast, Bite-size Japanese Podcast, and Akane's Japanese Class.

2. Full upload pull. Using the YouTube Data API, I pulled every public video from each channel along with its view count, duration, and publication date. Total candidate pool: ~9,000 videos. Shorts (under 60 seconds) were filtered out — they skew view counts and aren't really lessons.

3. Two-pass level classification. Each video was assigned to one of three buckets — beginner, intermediate, or advanced — using:

  • Title-based override (preferred). Explicit JLPT markers (N5, N4 → beginner; N3 → intermediate; N2, N1 → advanced) and Japanese level keywords (初級, 中級, 上級) take precedence.
  • Channel-default fallback. When no title signal exists, the video inherits its channel's typical level. This is rough — channels span levels — but it's the best signal available without watching every video.

4. Ranking and per-channel cap. Within each bucket, videos are sorted by view count (descending) and capped at 35 videos per channel, so no one creator dominates a level. The top 100 then make the cut. This produced 300 videos total — split into six YouTube playlists of 50 (a per-playlist limit imposed by the bulk-creation flow used).

The playlists

Tags

Within each bucket, additional tags allow finer filtering on the library page:

  • JLPT level — extracted from titles where the creator labeled it.
  • Format — heuristic from title keywords: lesson, podcast, vlog, conversation, interview, story-reading, grammar/vocab lesson, culture, news.
  • Length — short (<5 min), medium (5–15), long (15–30), very long (30+).
  • EN subs — videos that explicitly advertise English subtitles.

What this is not

This is a view-rank of CI content from specific established channels. It is not a comprehensive index of all Japanese CI on YouTube, not a quality-ranked list, and not a pedagogical curriculum. View counts reward virality, not necessarily learning value — but they do correlate well with watchability, which matters for input volume.

Individual videos may be miscategorized — a podcast on Akane's "advanced" channel might really be intermediate, and several of Shun's "intermediate" videos are explicitly N4 and belong with beginners. The title-based reclassification catches some of this; the rest is left to the learner's judgment.

Tools

Built with the YouTube Data API v3, Python for ranking, vanilla HTML/CSS/JS for the site, and YouTube's internal playlist API for bulk playlist creation. Hosted on GitHub Pages. No analytics, no tracking.
